
# CinemaEBookingApp
The term project for CSCI 4050 Software Engineering. A web-based application designed to allow users to browse and book showings for a movie online.

## Frontend

The frontend is built with React using Vite. Run the following commands to see the frontend:
```powershell
cd frontend
npm install
npm run dev
```



## Backend

The backend is built with Springboot to access the database. Run the following commands to run the backend:

```powershell
cd backend
.\mvnw.cmd spring-boot:run
```

## Database
The database is built with MongoDB integrated with MongoRepository for Springboot in the backend.
